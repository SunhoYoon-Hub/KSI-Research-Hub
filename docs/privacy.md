# 개인정보 보호 원칙

KSI Research Hub는 공개 연구 정보만 다룹니다.

- 구성원의 이메일, 전화번호, 학생번호와 학교 내부 계정을 공개하지 않습니다.
- KSI의 공식 수신 주소만 Owner의 동의에 따라 연락 목적으로 공개합니다.
- 구성원의 실명과 기여 내용은 당사자가 공개에 동의한 경우에만 표시합니다.
- 비공개 심사 자료와 개인 대화는 저장소에 기록하지 않습니다.
- 잘못 공개된 개인정보는 확인 즉시 비공개 처리 또는 삭제를 요청합니다.

연구 제안 및 참여 신청 화면에 입력한 내용은 사이트 서버에 저장되지 않습니다. 이메일 작성 버튼을 누르면 방문자의 이메일 프로그램으로 내용이 전달되며, 실제 전송은 방문자가 직접 확인하고 실행합니다.

방문 수는 같은 브라우저를 한국 날짜당 한 번 집계합니다. 브라우저에 임의의 익명 표식을 저장하고, Cloudflare Workers와 D1에는 날짜별로 달라지는 해시값과 집계 숫자만 기록합니다. 중복 확인용 해시값은 최근 한국 날짜 3일 동안만 유지하며, 날짜별 숫자와 누적 숫자는 보존합니다. 집계 코드에는 실명, 이메일, IP 주소를 저장하는 기능이 없습니다. Cloudflare와 GitHub의 서비스 운영 정보 처리는 각 서비스의 정책을 따릅니다.

누적 방문 수는 브라우저별 일일 방문의 합입니다. 다른 날 방문하거나 다른 기기·브라우저를 사용하면 다시 집계될 수 있습니다. 저장소를 차단한 브라우저는 집계 없이 숫자만 조회하며, 모든 저장소가 차단된 경우가 아닌 세션 저장소 사용 시에는 새 세션이 별도로 집계될 수 있습니다.
