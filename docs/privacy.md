# 개인정보 보호 원칙

KSI Research Hub는 공개 연구 정보만 다룹니다.

- 이메일, 전화번호, 학생번호와 학교 내부 계정을 공개하지 않습니다.
- 구성원의 실명과 기여 내용은 당사자가 공개에 동의한 경우에만 표시합니다.
- 비공개 심사 자료와 개인 대화는 저장소에 기록하지 않습니다.
- 잘못 공개된 개인정보는 확인 즉시 비공개 처리 또는 삭제를 요청합니다.
