# 연구 기록 작성 안내

새 연구 항목은 `projects.yml`에 등록하고, 필요한 경우 이 폴더에 개별 Markdown 문서를 추가합니다.

## 개별 연구 문서 양식

```markdown
# 연구 제목

## 기본 정보

- 분야:
- 상태: idea / drafting / review / revision / published
- 현재 버전:
- Zenodo:

## 연구 질문

## 연구 개요

## 진행 기록

## 동료평가 및 반영

## 버전 변경 내역
```

완성된 PDF 자체보다 연구 질문, 진행 상황, 검토 결과와 Zenodo 공개본의 연결을 우선하여 기록합니다.
