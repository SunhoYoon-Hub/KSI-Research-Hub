# KSI Research Hub

학생 연구의 **구상–집필–검토–개정–공개** 과정을 연결하는 KSI의 작업 허브입니다.

완성된 연구 성과는 Zenodo에 보존하고 DOI를 발급합니다. 이 저장소는 연구의 진행 상황, 동료평가, 수정 내역과 관련 자료를 연결합니다.

## 역할 구분

| 공간 | 역할 |
| --- | --- |
| GitHub | 연구 진행, 수정 기록, 동료평가, 공동 작업 |
| Zenodo | 완성본 보존, 버전 공개, DOI 발급 |
| KSI Research Hub | 연구 목록과 두 공간을 연결하는 안내소 |

## 연구 흐름

1. **구상** — 연구 질문과 목적을 Issue로 등록합니다.
2. **집필** — 자료와 원고를 작성하고 주요 변경 사항을 기록합니다.
3. **검토** — 동료평가 Issue에서 가독성, 논리, 근거, 인용을 점검합니다.
4. **개정** — 검토 의견을 반영하고 변경 내역을 정리합니다.
5. **공개** — GitHub Release를 만들고 Zenodo에 최종본을 보존합니다.

## 참여 방법

- 새 연구를 제안하려면 **New research proposal** Issue를 작성합니다.
- 연구를 검토하려면 **Peer review** Issue를 작성합니다.
- 문서 수정은 Pull Request로 제안합니다.
- 개인정보, 학교 내부 정보, 이메일과 비공개 대화는 올리지 않습니다.

자세한 기준은 [`CONTRIBUTING.md`](CONTRIBUTING.md)를 확인하십시오.

## 저장소 구성

```text
.
├── .github/ISSUE_TEMPLATE/  연구 제안·동료평가 양식
├── docs/                    향후 GitHub Pages 홈페이지
├── research/                연구 목록과 기록 양식
├── CONTRIBUTING.md          참여·검토 기준
└── README.md                KSI Research Hub 첫 화면
```

## 운영 원칙

- 저자와 기여자의 역할을 정확히 표시합니다.
- 공개된 자료와 인용의 출처를 명확히 밝힙니다.
- 동료평가는 연구자를 평가하는 일이 아니라 연구를 개선하는 일로 봅니다.
- 완성본과 작업 중인 자료를 명확히 구분합니다.
- 개인 식별 정보와 학교 내부 정보는 공개 저장소에 기록하지 않습니다.
